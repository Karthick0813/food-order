# SnackPass – Food Ordering System

SnackPass is a simple web-based food ordering application designed to simulate the basic workflow of ordering food through an online menu.

## Overview

The idea behind this project was to build an interactive food ordering interface where users can browse available food items, select multiple items, manage their cart and confirm their orders.

The project was developed to gain practical experience in HTML, CSS and JavaScript.

## Features

### 1. Categorized Food Menu
- Displays food items under Snacks, Drinks and Meals.
- Allows users to filter the menu based on food categories.
- Shows food images, item names and prices.

### 2. Shopping Cart Management
- Add multiple food items to the cart.
- Increase or decrease item quantities.
- Automatically remove an item when its quantity reaches zero.
- View selected items and their quantities.

### 3. Automatic Price Calculation
- Calculates the total amount based on selected items and quantities.
- Updates the cart total whenever the order is modified.

### 4. Order Confirmation
- Generates a unique-looking order token for each confirmed order.
- Displays the selected items and their quantities.
- Shows an order confirmation message and preparation status.

### 5. New Order Option
- Allows users to start a fresh order after completing the previous one.

## Technology Stack

- **HTML5** – Structure of the application.
- **CSS3** – Styling, responsive layouts and visual presentation.
- **JavaScript** – Menu rendering, category filtering, cart management, quantity updates, price calculation and order confirmation.


## Project Scope

This is a frontend demonstration project. Order information and generated tokens are handled on the client side; there is no backend database or persistent order management.
